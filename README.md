# ( 🚖 ) —  A&C Taxi Booking Application

---
A simple GUI **taxi booking application** developed using PyQt6 with SQLite3 integration.  

---
### Features (Full Support):
1. **Customer**: Make, cancel and view bookings.
2. **Driver**: View assigned bookings and manage ride progression.
3. **Administrators**: Manage driver assignment.

### Bonus Features (In Development):
1. **Customer**: Save custom addressing, Driver Application.
2. **Driver**: Driver profiles.
3. **Admin**: Review Driver Applications, User Account Modification.

# Getting Started

---

### 1. Create the virtual environment
```bash
python -m venv venv
```

### 2. Activate the virtual environment
### Windows (Powershell)
```bash
venv\Scripts\activate
```
### macOS/Linux
```bash
source venv/bin/activate
```

### 3. Install dependencies
```bash
pip install -r requirements.txt
```

### 4. Run the application
```bash
python main.py
```
